# Офлайн-режим (PWA без Workbox)

Одностраничный сайт без сборки; офлайн сделан по рецепту из `colombia-birds`, урезанному под масштаб.

## Решения (п. 0 рецепта)

1. **Кто пользуется.** Только мы двое. Пакет всё равно лёгкий, поэтому ограничений по размеру нет.
2. **Что в пакете.** Всё: `index.html`, `offline.js`, Leaflet, иконки, 46 фото птиц по 500 px и 12 тайлов OSM
   стартового вида карты (z12). Итого ≈ 3 МБ. Крупных фото, аудио и видео нет.
3. **Явное включение.** Пакет качается только по кнопке в разделе «Офлайн». При обычном просмотре в кэш попадает
   то, что открыли (страница, скрипты, просмотренные фото и тайлы).
4. **Свежесть.** Страница из кэша сразу, свежая копия в фоне (stale-while-revalidate); плашка «Есть новая
   версия · Обновить» при отличии `version.json` от `<meta name="build-version">`.
5. **Обновление пакета.** «Проверить» бесплатно; скачивание по кнопке с размером «≈ N МБ».
6. **Платформа.** iPhone: добавить на экран «Домой» и качать оттуда (своё хранилище). Android: Chrome.

## Как устроено

- `scripts/build-offline.mjs` собирает `dist/` из исходников (`index.html`, `offline.js`, `manifest.webmanifest`,
  `icons/`, `vendor/`, `img/`) и генерирует `offline-manifest.json`, `version.json`, `sw.js` (из
  `sw.template.js` с вшитой версией) и `<meta name="build-version">`. Версия это короткий SHA коммита
  (`GITHUB_SHA` в CI). Хэш страницы считается без строки с версией, иначе каждый деплой перекачивал бы её.
- `sw.template.js`: два кэша `pages-v1` (свой origin) и `media-v1` (тайлы, шрифты). Только GET; запросы с
  `cache: no-cache | reload | no-store`, кроме навигаций, не перехватываются (так загрузчик пакета обходит
  воркер); `sw.js`, `version.json`, `offline-manifest*.json` всегда из сети. Навигация: кэш → фон.
  ревалидация; нет в кэше → сеть, при ошибке заглушка 503. Свой origin: кэш, для не-картинок фоновая
  ревалидация; промах → сеть + положить. Чужой origin: кэш → сеть + положить.
- `offline.js`: регистрация (`register('sw.js', { scope: './', updateViaCache: 'none' })`), загрузка
  манифеста, диф по `localStorage['offline.vers']` (`{url: ver}`), прогресс всегда пересчитывается как
  «файлы манифеста в кэше / всего», параллелизм 6, повторы на сетевых ошибках и 5xx/429/408 (3 попытки,
  `Retry-After`), `storage.persist()`, Wake Lock, `AbortController`, чистка лишнего после полного прогона,
  диагностика открыта по умолчанию, плашки «Офлайн · данные от …» и «Есть новая версия».
- Tест `tests/offline.spec.mjs` (Playwright, обычный node-скрипт) с сервером `tests/server.mjs`, у которого
  хуки задержки и «N раз 503». Проверяет: скачивание пакета с одним 503, отдачу из кэша при медленном сервере,
  видимость изменённой страницы со второго визита, рендер страницы и фото офлайн, плашку офлайн, фолбэк любой
  навигации на закэшированную страницу. Запускается в CI перед деплоем.

## Локально

```
node scripts/build-offline.mjs
npm i --no-save playwright@1.56.1   # один раз
node tests/offline.spec.mjs
```

## Ограничения

- GitHub Pages кэширует до 10 минут: сигнал «новая версия» и фоновое обновление приходят с этой задержкой.
- Карта офлайн показывает только сохранённые тайлы стартового вида (z12). Приближение и сдвиг без сети пустые.
- Тайлы и шрифты кэшируются как есть по ключу-URL; замена файла под тем же URL подхватится только через
  «Удалить пакет».
- Удалённый с сайта файл остаётся в кэше до следующего полного обновления пакета.
- Одна страница, поэтому любая навигация офлайн отдаёт её же (заглушка 503 показывается, только если страница
  ещё ни разу не была сохранена).

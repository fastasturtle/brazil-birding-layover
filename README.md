# Сан-Паулу за 6,5 часов: птицы и обед

Одностраничный гид для пересадки в аэропорту Гуарульос (GRU): план по времени,
логистика аэропорта, парк для бёрдвотчинга (Parque Ecológico do Tietê + Bosque Maia),
карточки птиц с пометкой «нет в Колумбии», где спокойно поесть, план Б.

Сайт: `index.html` в корне, без сборки. Деплой на GitHub Pages через
`.github/workflows/pages.yml` при пуше в `main`.

## Включить GitHub Pages (один раз)

Settings → Pages → Build and deployment → Source: **GitHub Actions**.
После мержа в `main` workflow опубликует сайт по адресу
`https://<owner>.github.io/brazil-birding-layover/`.
